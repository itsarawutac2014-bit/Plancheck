# 📦 Corrugated Plan Checker (ระบบตรวจสอบแผนผลิตกระดาษลูกฟูก M1–M5)

แดชบอร์ดเว็บแอปพลิเคชันสำหรับพนักงานวางแผนและฝ่ายผลิต ใช้ตรวจสอบ **ความผิดปกติของแผนผลิตแผ่นกระดาษลูกฟูก** จากไฟล์ Excel (`.xlsx`, `.xls`, `.csv`) โดยทำงานบนเบราว์เซอร์ 100% (ไม่ต้องติดตั้งโปรแกรมเสริม และไม่ต้องใช้ฐานข้อมูลหลังบ้าน) พร้อมขึ้นใช้งานบน **GitHub Pages** ได้ทันที

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **ลากไฟล์วางได้ทันที (Drag & Drop Excel / CSV)**
   - รองรับไฟล์แผนผลิต Excel (`.xlsx`, `.xls`, `.csv`) ทุกชีตที่มีตารางแผนผลิต (`PLAN`)
   - ค้นหาหัวตารางอัตโนมัติ (`ลำดับที่`, `Prod Order No`, `M5.`–`M1.`, `กว้าง W`, `ยาวรวม (เมตร)`)
2. **ระบบตรวจจับการเปลี่ยนโค้ดกระดาษ M1–M5 และออเดอร์พ่วงอัจฉริยะ**
   - ตรวจสอบชั้นกระดาษ **`M5, M4, M3, M2, M1`** และ **หน้ากว้างกระดาษ (`กว้าง W`)** เทียบกับออเดอร์ก่อนหน้าและออเดอร์ถัดไป
   - คำนวณ **ระยะพ่วงสะสมรายชั้นกระดาษ** และ **สถานะขบวนพ่วง (`DeCode`: `11` ออเดอร์เดี่ยว, `10` เปิดหัวขบวน, `00` พ่วงกลางขบวน, `01` พ่วงท้ายขบวน)**
   - แจ้งเตือนเมื่อพบออเดอร์ที่มีชั้นกระดาษ `M1–M5` **ไม่ต่อเนื่อง (เปลี่ยนโค้ดกระดาษ/เปลี่ยนหน้ากว้าง)** และมี **`ยาวรวม (เมตร) < 300 เมตร`** (สามารถปรับตัวเลขเกณฑ์เมตรขั้นต่ำได้ตามต้องการ)
3. **แสดงผลเปรียบเทียบเข้าใจง่ายสำหรับพนักงานทั่วไป**
   - การ์ดสรุปจุดผิดปกติ แสดงโค้ดกระดาษ **ก่อนหน้า (⬆) ➔ ปัจจุบัน ➔ ถัดไป (⬇)** พร้อมไฮไลต์สีแดงเฉพาะชั้น `M` ที่เป็นปัญหา
   - สลับดูได้ 3 โหมด:
     - 🚨 **เฉพาะออเดอร์ผิดปกติ (ไม่พ่วง < 300 ม.)**
     - ⚡ **ทุกใบที่เปลี่ยนโค้ด < 300 ม. (รวมพ่วงหัว/ท้ายขบวน)**
     - 📋 **แสดงทั้งแผน**
4. **บันทึกรูปภาพความละเอียดสูง (Ultra HD 3x PNG Export)**
   - กดปุ่ม **"บันทึกรูปภาพรายการที่แสดง"** หรือ **"คัดลอกรูปภาพ (Ctrl+V)"** เพื่อส่งต่อใน LINE หรือกลุ่มงานได้ทันที ภาพคมชัดระดับ 3x Retina
   - สามารถกดแคปรูปแยกเฉพาะการ์ดออเดอร์ที่มีปัญหาได้รายใบ

## 🚀 วิธีใช้งาน (How to Use)

1. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ทั่วไป (Chrome, Edge, Safari) หรือเข้าผ่านลิงก์ GitHub Pages
2. โยนไฟล์ Excel แผนการผลิตลงในกรอบ **"ลากไฟล์แผนการผลิต Excel มาวางที่นี่"** (หรือกดปุ่ม **"โหลดแผนตัวอย่าง"** เพื่อดูตัวอย่างแผนวันที่ 10/11/69 PLAN 1 MC BHS)
3. ระบบจะคัดกรองและแสดงออเดอร์ที่ผิดปกติขึ้นมาทันที
4. กดปุ่ม **"บันทึกรูปภาพรายการที่แสดง (PNG คมชัดสูง)"** หรือ **"คัดลอกรูปภาพ"** เพื่อส่งต่อให้ทีมงาน

## 🌐 วิธีนำขึ้น GitHub Pages (Deployment)

โปรเจกต์นี้เป็น Static Web Application เต็มรูปแบบ สามารถเปิดใช้งานผ่าน **GitHub Pages** ได้ฟรีตามขั้นตอนดังนี้:

```bash
git init
git add .
git commit -m "Initial commit: Corrugated Plan Checker Dashboard"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/<ชื่อ-repo>.git
git push -u origin main
```

จากนั้นไปที่หน้า Repository บน GitHub:
1. ไปที่เมนู **Settings** ➔ **Pages**
2. ในหัวข้อ **Build and deployment (Source)** เลือก `Deploy from a branch`
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์พร้อมส่งให้พนักงานใช้งานได้ทันที!
